# 🏋️ 운동기록 — Claude Code Skill

애플 피트니스 스크린샷 한 장으로 노션 운동 기록을 자동화하는 **Claude Code 스킬**.

운동 후 피트니스 앱 요약 화면을 캡처해서 Claude에게 보내면, 데이터를 자동으로 파싱해 노션 월별 페이지에 기록하고 AI 트레이너 피드백까지 달아줍니다.

---

## ✨ 주요 기능

| 기능 | 설명 |
|------|------|
| 📸 이미지 자동 파싱 | 애플 피트니스 요약 화면에서 날짜, 운동 종류, 시간, BPM, 칼로리, 강도 자동 추출 |
| 🗂️ 노션 월별 자동 정리 | 월이 바뀌면 `2026년_07` 등 새 페이지 자동 생성 |
| 🔄 컬럼 자동 확장 | 기존 테이블에 `트레이너 피드백` 컬럼이 없으면 자동 추가 |
| 🏃 운동 종류 자동 인식 | 실내 사이클링→사이클, 달리기→런닝, 근력→웨이트 등 자동 매핑 |
| ➕ 복합 운동 통합 | 같은 날 여러 운동 → 한 행에 합산 (사이클+런닝, 칼로리 합계 등) |
| 📝 메모 자동 취합 | 이미지 외 텍스트 입력 내용이 메모 컬럼으로 자동 저장 |
| 💬 AI 트레이너 피드백 | BPM 존 분석, 칼로리 평가, 목표 체중 진행률, 다음 운동 어드바이스 |
| 📊 피드백 노션 자동 기록 | 트레이너 피드백이 노션 테이블 컬럼에도 자동 저장 |

## 🚀 설치 방법

### 1. Claude Code 설치

[Claude Code 공식 문서](https://docs.anthropic.com/claude-code)를 참고해 설치합니다.

### 2. 스킬 다운로드

```bash
git clone https://github.com/korleinster/workout-claude-skill.git
```

### 3. 노션 MCP 연결

Claude Code에서 노션 MCP를 연결합니다:

1. Claude Code 설정 → MCP Servers
2. Notion MCP 추가 및 노션 계정 연동

### 4. 노션 페이지 ID 설정

`SKILL.md` 파일에서 아래 두 항목을 본인 노션 페이지 ID로 교체합니다:

```
ROOT_PAGE_ID  → 운동 루트 페이지 ID (노션 URL에서 확인)
YEAR_PAGE_ID  → 연도 페이지 ID (예: 2026년 페이지)
```

노션 페이지 URL에서 ID 확인 방법:
```
https://www.notion.so/workspace/페이지-제목-[여기가 ID]
```

### 5. 사용자 프로필 수정

`SKILL.md` 5단계 "사용자 정보" 섹션에 본인 정보를 입력합니다:

```
- 키: 187cm / 현재 체중: 88kg / 목표: 80kg
- 운동: 실내 사이클링 주 3회
- 인터벌: 90rpm 1분 → 110rpm 2분 → 130rpm 30초
```

### 6. 스킬 등록

```bash
# Claude Code 스킬 디렉토리에 복사
cp -r workout-claude-skill ~/.claude/skills/운동기록
```

## 📱 사용 방법

### 기본 사용

1. 운동 후 **애플 피트니스 앱** → 운동 요약 화면 스크린샷
2. Claude Code 대화창에서:

```
/운동기록 [스크린샷 첨부]
```

### 체중 추가

```
/운동기록 오늘 체중 87.5kg [스크린샷 첨부]
```

### 메모 추가

```
/운동기록 오늘 허리 조금 뻐근했음 [스크린샷 첨부]
```

### 복합 운동 (같은 날 여러 운동)

```
/운동기록 [사이클 스크린샷] [런닝 스크린샷]
```
→ 자동으로 한 행에 합산 기록

## 💡 트레이너 피드백 예시

```
평균 BPM 145로 심폐 강화 존(140~160)에서 운동하셨고,
최고 BPM 167까지 도달한 고강도 세션이었습니다.
30분에 348kcal 소모는 매우 우수한 성과예요.
체중 88.2kg으로 목표 80kg까지 8.2kg 남았는데,
현재 페이스 유지 시 6~8주 내 도달 가능합니다.
다음 운동에서는 130rpm 구간을 30초→45초로 늘려보세요.
```

**BPM 존 기준:**
- ~120 BPM: 지방 연소 존
- 120~140 BPM: 유산소 존 (적정)
- 140~160 BPM: 심폐 강화 존 (다이어트 효과적 ✅)
- 160+ BPM: 최대 심박 존

## 🗂️ 노션 페이지 자동 구성

```
운동 (루트 페이지)
  └ 2026년
       └ 2026년_01
       └ 2026년_02
       └ ...
       └ 2026년_06  ← 현재 월에 자동 기록
       └ 2026년_07  ← 7월이 되면 자동 생성
```

월이 바뀌면 새 페이지를 자동 생성하고, 이전 달 데이터는 그대로 유지됩니다.
